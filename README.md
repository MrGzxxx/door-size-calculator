# 工业门尺寸与价格估算器 · door-size-calculator

给门业销售 / 报价 / 安装场景的快速估算小工具：输入门洞尺寸、门型、数量，输出**面积、用料估算与参考价格区间**。两个版本、零第三方依赖：

- `calculator.py` — Python 命令行版（Python 3.6+）
- `calculator.html` — 单文件网页版（双击用浏览器打开即可，离线可用）

> 由 **重庆立高门业有限公司** 开源 · 官网 <https://mrgzxxx.github.io/ligao/>
> ⚠️ 估价仅供参考，实际以现场测量与正式报价为准。

## 使用（Python）

```bash
python calculator.py                                   # 交互式
python calculator.py --list                            # 查看支持门型与参考系数
python calculator.py --type 快速卷帘门 --w 3.0 --h 3.0 --qty 2
```

输出示例：

```
门型: 快速卷帘门    (PVC 软帘，高频通行，适合车间 / 仓库)
单樘: 3.00m × 3.00m    数量: 2
单樘面积: 9.00 ㎡    总面积: 18.00 ㎡
用料估算(单樘): 门体材料 ≈ 9.72 ㎡ ; 导轨/边柱 ≈ 7.2 m
参考价: ¥9,900 ~ ¥16,200   (中值 ¥13,050)
⚠️  结果为估算值，实际以现场测量与正式报价为准。
```

## 使用（网页版）

浏览器打开 `calculator.html`，选择门型、填写尺寸与数量，点「估算」。无需联网、无需安装。

## 计算逻辑

- 面积 = 宽 × 高（m²）
- 门体材料 ≈ 面积 × 1.08（搭接 / 裁剪损耗）
- 导轨 / 边柱长度 ≈ (高 + 0.6) × 2（米）
- 参考价 = 总面积 × 单价系数区间；超过常规尺寸会给出分节 / 定制提示

## 自定义价格系数

默认系数为市场**示例值**（不同地区、品牌、配置差异很大），请按当地行情校准：

- Python 版：编辑 `calculator.py` 顶部 `DOOR_TYPES` 中的 `price_low` / `price_high`
- 网页版：编辑 `calculator.html` 中同名的 `DOOR_TYPES`
